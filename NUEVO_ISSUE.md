**Título del Issue:** `feat: Adoptar el ciclo PAE para la generación de código con el especialista FlutterDev`

---

**Descripción (User Story):**

Como **desarrollador** del proyecto "Paseo-Perro",
**quiero** utilizar al especialista `FlutterDev` del ecosistema Apptiva para generar el código base de un nuevo widget,
**para que** podamos acelerar el desarrollo, asegurar la consistencia del código y aprender a interactuar correctamente con el nuevo ecosistema de IAs.

Esta User Story servirá como caso práctico para que el equipo técnico se familiarice con el nuevo **Protocolo Maestro de Interacción: Planificar, Aprobar, Ejecutar (PAE)**.

---

**Criterios de Aceptación:**

-   [ ] Se ha realizado una solicitud formal al especialista `FlutterDev` para la creación de un widget simple (ej. un `DogWalkCard` que muestre la fecha y duración de un paseo).
-   [ ] El especialista `FlutterDev` ha presentado un plan de acción detallado (ficheros a crear, código a generar).
-   [ ] El equipo ha revisado y aprobado explícitamente el plan.
-   [ ] El especialista `FlutterDev` ha ejecutado el plan y ha generado el código del widget en una nueva rama.
-   [ ] El código generado ha sido revisado por el equipo y cumple con la arquitectura del proyecto.
-   [ ] El equipo ha documentado en sus notas internas las lecciones aprendidas durante el proceso de interacción PAE.
